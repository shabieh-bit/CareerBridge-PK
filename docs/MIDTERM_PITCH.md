## Q&A (2 minutes)
**Q: Is the percentage truly 'eligibility'?** A: No, it is the fraction of manually entered required skills found in the profile. Other requirements are not automatically assessed.
**Q: Are employer applications submitted?** A: No. CareerBridge's 'Apply and track' action records an internal status.
**Q: Where is data stored?** A: Student records are stored in a hosted PostgreSQL database and accessed through an authenticated API (only say hosted after deployment is verified).
**Q: How is CareerBridge different?** A: It combines simple skill-gap feedback, an action plan and personally saved opportunity tracking.
**Q: How do you generate revenue?** A: Future options might include campus partnerships or optional premium tools, but revenue is not validated.
**Q: How is personal information protected?** A: Passwords are hashed, sessions use httpOnly cookies and API queries use authenticated user IDs. Further security work is needed before broader use.
